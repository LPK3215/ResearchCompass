ResearchCompass

科研罗盘 — 面向学术文献检索、分析和研究证据管理的科研智能体平台

v1.0.0 · FastAPI + LangGraph · Vue 3 · Docker Compose

项目简介

🎯

核心价值

基于开源智能体框架 Yuxi 构建，针对科研领域二次开发，实现学术语义分块、混合检索、论文引用图谱、多 Agent 分析、证据综述等科研业务能力。

💡

差异化优势

提供可核查证据（关联真实论文分块回到 PDF 原文）和可复现实验（固定数据集、模型配置和语料指纹），不根据缺失样本推断效果。

⚡

核心能力

  • 对话式研究 Copilot
  • 学术语义分块（按论文章节）
  • 研究项目执行中心
  • 双模式科研检索
  • 多 Agent 论文分析
  • 可核查证据综述
  • 可复现消融实验
  • 匿名用户研究

快速开始

1

前置要求

Docker Engine、Docker Compose，至少一个兼容 OpenAI 接口的对话模型和向量模型。

2

初始化并启动

bash 
# Windows
.\scripts\init.ps1
docker compose up -d --build

# Linux / macOS
./scripts/init.sh
docker compose up -d --build
服务地址
Webhttp://localhost:5173
API 健康检查http://localhost:5051/api/system/health
