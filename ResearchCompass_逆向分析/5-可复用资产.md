# 5. 可复用资产

> 以下思路/模式/代码可迁移到任意"RAG + Agent + 领域"类项目。

## 5.1 学术章节分块模式（高复用）

**来源**：`knowledge/chunking/ragflow_like/parsers/academic.py`
**可迁移点**：
- Chunk 元数据模型：`section_path`(层级路径) + `section_level` + `section_index` + `contains_equations` + `prev/next_section_path`
- 切分策略：先按语义边界（章节树）分，超阈值再按句/段二次切，过短向上合并
**适用**：任何"文档结构即语义"的 RAG（法律条文、API 文档、教材、专利）。直接抄 `AcademicSectionChunker` 的结构，换 section 识别器即可。

## 5.2 领域错误 → HTTP 状态码映射（中复用，模式级）

**来源**：`research_copilot_service.py` L40-52 + `research_router.py` L30-56
**可迁移点**：
```python
# service 层定义与 Web 无关的领域错误
class ResearchNotFoundError(Exception): ...
class ResearchDomainError(Exception): ...
# router 层统一转换
@app.exception_handler(ResearchDomainError)
async def _handle_domain_error(req, exc):
    code = 404 if isinstance(exc, ResearchNotFoundError) else 400
    return JSONResponse(status_code=code, content={"detail": str(exc)})
```
**适用**：任何 FastAPI + service 分层项目。让 service 可在无 Web 上下文单测。

## 5.3 Run 状态机（中复用）

**来源**：`research_search_service` / `research_synthesis_service` / `academic_paper_analysis_service` 的 `SearchRun`/`SynthesisRun`/`AnalysisRun`
**可迁移点**：长任务统一抽象为 `Run` 对象，状态 `pending→running→completed/failed`，携带 `error` 字段；前端轮询/订阅状态而非阻塞。
**适用**：所有"提交后异步跑、前端看进度"的任务（批处理、评测、爬取）。

## 5.4 综述反幻觉双保险（高复用，核心资产）

**来源**：`research_synthesis_service._verify_synthesis_claims` (L885) + `_cluster_by_section`
**可迁移点**：
1. 生成与校验分离（两趟 LLM 调用）
2. 每句 claim 挂 `source_chunk_ids` + 校验态（supported/contradicted/unverified）
3. 聚类优先用结构元数据（section_path）而非纯 embedding，省钱且更准
**适用**：任何"基于检索内容生成自然语言"且要求可信的场景（客服话术、报告生成、合规摘要）。这是本项目最有价值的专利级思路。

## 5.5 引用图双向边 + 冲突 merge（中复用）

**来源**：`academic_graph_service.py`
**可迁移点**：引用/依赖类关系图用双向边（`cites`/`cited_by`）；节点以归一化 key（DOI/标题）去重 merge，避免重复节点。
**适用**：依赖图谱、知识关联、文献计量。

## 5.6 Agent 运行态接缝模式（高复用，架构级）

**来源**：`run_worker.py` L51/L62-70（`RESEARCH_CONTEXT_SOURCES` + `_trusted_research_context`）
**可迁移点**：当在通用 Agent 框架上做领域扩展时，用"agent_slug 常量 + source 白名单"作为唯一接缝，框架侧只认 slug 与白名单，领域侧负责注入可信上下文。改框架原语为"识别 + 委托"。
**适用**：任何 L2 框架上叠 L3 领域层的项目（与本项目同构）。

## 5.7 报告确定性拼装（低复用，但值得学）

**来源**：`research_project_report_service.py`
**可迁移点**：对外交付物（报告/导出）走"读库 + 模板渲染"路径，刻意不调 LLM，保证可复现可审计。
**适用**：任何需要"同一输入多次导出结果一致"的交付场景（合同、证书、合规报告）。
