# 0. 仓库画像（类型判断 + 依据）

## 0.1 类型判断

| 维度 | 归类 | 判断依据（源码证据） |
|------|------|----------------------|
| **语言 / 栈** | **多语言 monorepo** | 后端 `Python`（LangGraph v1 + FastAPI），前端 `web/` 为 `Vue 3 + TypeScript`（`pnpm` 管理，见 `AGENTS.md` 前端规范），基础设施 `docker/`、`docker-compose.yml`、`Makefile` |
| **领域 / 问题** | **RAG 知识库 + Agent 编排 + 学术数据处理** 三合一 | `AGENTS.md` 原文："基于 LangGraph v1 + Vue.js + FastAPI + LightRAG 架构构建"；学术分块解析器、引用图谱、四阶段论文分析工作流、混合检索均属学术数据治理范畴 |
| **规模形态** | **平台（L2 框架 + L3 领域层）** | 框架层 `Yuxi` 提供知识库/知识图谱/多Agent运行时；领域层 `ResearchCompass` 在其上叠加科研业务。`backend/package/yuxi/` 下 `services` 449+ `.py` 文件 |
| **成熟度** | **生产级（工程化、可部署、非原型）** | `docker-compose.yml` 提供 Compose 一键启动 + 热重载；`.env` 管理密钥；`run_worker.py` 用 ARQ 做异步任务队列 + 重试；`backend/server/routers/research_router.py` 1747 行完整 REST 契约；鉴权、租户隔离、审计齐全 |

## 0.2 关键证据文件清单（已读源码）

- `README.md` / `AGENTS.md` / `ARCHITECTURE.md`：项目定位与架构边界声明
- `docker-compose.yml`：服务编排（api / web / postgres / redis / 向量库 / lightrag / arq worker）
- `backend/server/routers/research_router.py`：科研领域全部 HTTP 接口（核心暴露面）
- `backend/package/yuxi/services/research_*_service.py`、`academic_*_service.py`：科研业务逻辑
- `backend/package/yuxi/agents/toolkits/research/tools.py`：27+ 科研领域工具（@tool 注册）
- `backend/package/yuxi/knowledge/chunking/ragflow_like/parsers/academic.py`：学术章节分块解析器
- `backend/package/yuxi/knowledge/graphs/academic_graph_service.py`：引用图谱同步

## 0.3 核心抽象（一句话）

**Yuxi = 通用智能体底座（原语集合）；ResearchCompass = 在 3 个扩展槽（service / tool / parser）填空的科研领域层。**
作者刻意不重写框架，只做"外科手术式"的领域扩展 + 一处运行态接缝（`run_worker.py` 识别 `RESEARCH_COPILOT_AGENT_SLUG`）。

## 0.4 依赖栈（关键取舍）

- **编排**：LangGraph v1（`StateGraph` / `ToolNode` / `ToolRuntime`），非自定义状态机
- **检索**：混合检索（关键词 BM25 + 向量语义），重排用 `langchain_community` 的 `FlashrankReranker`（见 1-架构全景 §核心抽象）
- **图存储**：LightRAG 知识图谱 + 自研引用图谱（`academic_graph_service.py` 双向同步 Neo4j/Postgres）
- **异步**：ARQ（Redis-backed 任务队列）+ PostgreSQL（业务数据）+ Redis（缓存/队列/取消信号）
- **前端**：Vue 3 + TypeScript + pnpm + lucide-vue-next 图标 + less（base.css 颜色变量）

> ⚠️ 待核实：`docker-compose.yml` 中向量库具体选型（Milvus / Qdrant / pgvector）未逐行确认；从 `ARchitectURE.md` 推断为 pgvector 或外部向量服务，不影响架构判断。
