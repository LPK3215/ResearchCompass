# 项目档案（内部文档）

本目录保存 ResearchCompass 的**过程性 / 内部**文档：立项方案、决策依据、实现跟踪、历史问题清单与验收记录。它们解释"为什么做成这样"，与面向使用者的功能文档（`docs/intro/`）分开维护。

> 本目录通过 VitePress `srcExclude` 排除在文档站构建之外，只在仓库内阅读，不会发布到文档站点。

## 怎么用这些文档

- 想知道**现在能做什么、怎么用**：看 [能力全景](../intro/capabilities.md) 与 [从选题到成稿](../intro/research-workflow.md)。
- 想知道**为什么这样设计**：看本目录的《规划与决策》。
- 想知道**改了什么**：看 [版本变更记录](../develop-guides/changelog.md)。
- 想知道**怎么跑起来 / 怎么排查**：看 [快速开始](../intro/quick-start.md) 与 [本地开发环境](../develop-guides/local-dev-environment.md)。

## 维护约定

- 新产生的方案、决策、验收记录统一放在本目录，不再堆在仓库根目录。
- 文件名带日期（如 `验证记录-2026-10-20.md`），便于排序与追溯；新建文档的文件名使用 ASCII 英文。
- 面向使用者的能力说明只写在 `docs/intro/`，避免同一份内容两处维护。
