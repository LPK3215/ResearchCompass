# 能力全景：这个系统到底能干什么

ResearchCompass（科研罗盘）是一个**面向学术文献的科研智能体平台**：把你手上的论文变成一个可检索、可核查、可追溯的私有文献库，再用 AI 把"找证据 → 读论文 → 写综述 → 立课题 → 出报告"这条链路串起来。

一句话记住它：**它不替你想观点，它负责让你写的每一句话都能指回一篇真实论文的某一段。**

## 你可以在它上面完成的 8 件事

### 1. 建一个私有文献库

把 PDF 论文批量变成结构化知识：按 Abstract / Introduction / Method / Experiments / Conclusion 学术章节分块，保留页码、字符区间、公式表格元数据。

| 入口 | 关键操作 | 产出 |
| --- | --- | --- |
| 知识与工具管理 → 知识库 → 新建知识库 | 选嵌入模型与分块策略 | 一个 Milvus 知识库 |
| 知识库详情 → 文件管理 → 上传 | 上传 PDF/Office/网页等，自动解析入库 | 带章节结构的 chunk 与索引 |

### 2. 用自然语言找到"有出处的证据"

不是给一堆链接，而是给出**论文 + 章节 + 原文片段 + 相似度/重排分**，点开能回到 PDF 原文位置。

发现阶段可同时查询 Semantic Scholar、OpenAlex 与 Crossref 并按 DOI 合并结果，单个源不可用时其余来源继续返回；也可以从库里某篇论文的参考文献 / 被引文献做“引文滚雪球”，勾选后批量纳入本地库（默认只取元数据，开放获取可选下载全文）。

| 入口 | 关键操作 | 产出 |
| --- | --- | --- |
| 科研罗盘 → 智能检索 | 选检索模式（本地混合 / 严格图谱）、年份、返回论文数，输入研究问题 | 带证据片段的检索运行（可保存、置顶、重跑） |
| 科研罗盘顶部 → 导入公开论文 | 输入标题 / DOI / Paper ID，查看逐源状态与来源标记后导入 | 公开论文进入解析与索引队列 |
| 科研罗盘顶部 → 导入文献 | 上传或粘贴 BibTeX / RIS 文件 | 仅元数据入库，不参与全文检索 |
| 论文库 → 点开论文 → 引文滚雪球 | 选参考文献或被引文献 → 勾选 → 导入 | 元数据入库（可再补全文） |

### 3. 把一批论文变成结构化综述

系统先做跨论文检索，再让模型产出"主题综述 + 核心结论 + 证据矛盾 + 研究局限 + 研究空白"，每条结论必须绑定**已验证**的证据，无法支撑的结论会被单独标为"未支持结论"。

筛选阶段可逐篇或批量标记纳入 / 排除并填写理由，顶部给出识别 / 纳入 / 排除 / 待定计数，可导出 CSV；AI 只能读取筛选结果，不会替你做纳入判断。

| 入口 | 关键操作 | 产出 |
| --- | --- | --- |
| 科研罗盘 → 证据综述 → 生成综述 | 失败于证据校验时，点"一键录入并验证"再"重新生成" | 可导出的 Markdown / DOCX 综述 |
| 科研罗盘 → 论文库 → 筛选条 | 勾选论文 → 标记纳入 / 排除 / 待定（可填理由） | 筛选计数与 CSV |

### 4. 读懂单篇论文（含多 Agent 协作分析）

结构化提取研究问题、方法、数据集、实验结果与局限；也可以跑四阶段多 Agent 分析（结构提取 → 创新点 → 方法学 → 研究空白），并把单 Agent 与多 Agent 的报告做成 A/B 盲评。

分析页还提供论文作用域对话：追问只检索本篇论文的切片，回答带 chunk 引用与页码，点击可回到 PDF 原文。

论文详情页可按章节生成逐段中英对照，保留页码定位；译文只用于阅读辅助，不写入数据库与证据库。对照翻译在后台任务中执行并显示进度，离开页面后再回来可继续查看进行中任务或上次结果。

| 入口 | 关键操作 | 产出 |
| --- | --- | --- |
| 论文库 → 点开论文 → 论文分析 | 选择分析模式并运行 | 结构化分析报告（可归集到项目） |
| 论文分析页 → 论文对话 | 输入问题追问（如“实验设置是什么”） | 带 chunk 引用与页码的回答 |
| 论文详情页 → 对照翻译 | 选章节 → 生成对照（后台执行，带进度） | 逐段中英对照（带页码） |
| 论文库 → 点开论文 → 阅读笔记 | 选中章节文字添加批注 → 写笔记 → 导出 Markdown | 个人笔记与分块内高亮 |
| 科研罗盘 → 分析对比 | 新建对比 → 生成两版报告 → 盲审打分 → 汇总 | 策略对比结论（只统计真实人工评分） |

### 5. 管理一个真实课题（项目执行中心）

以课题为单位管理里程碑、任务、优先级、截止日期与阻塞状态，进度由任务自动计算；论文、检索、综述、分析、实验都能归集进项目并挂到具体执行项上。

| 入口 | 关键操作 | 产出 |
| --- | --- | --- |
| 科研罗盘 → 研究项目 → 新建项目 | 填研究问题 → 建里程碑/任务 → 归集成果 → 登记风险 | 项目看板 + 最近活动时间线 |
| 项目详情 → 导出报告 | 选 Markdown / Word / CSV | 可直接交给导师或组会的项目报告 |

### 6. 看清研究地图

引用图谱（谁引用了谁、两跳关系）、研究趋势（年份/关键词演化）、研究机会（按增长、近期性、覆盖度、图谱缺口排序的机会分）。

| 入口 | 关键操作 | 产出 |
| --- | --- | --- |
| 科研罗盘 → 引用图谱 | 先"同步引用图谱"，再浏览/点选节点 | 引用网络（可查看关系证据） |
| 科研罗盘 → 研究趋势 / 研究机会 | 选知识库与年份区间 | 趋势统计与机会排序（含判断依据） |

### 7. 让 AI 助手替你跑流程

AI 研究助手会带着当前知识库、项目、页面区域和选中对象的上下文工作，能调领域工具完成检索、论文分析、单篇追问、论文笔记读写、引文滚雪球、文献筛选记录、证据综述与证据治理、引用图谱同步、趋势与机会、项目与任务变更、用户评测、分析对比、外部论文导入、论文元数据补全以及报告/引文/评测数据导出；删除、完成、归档、证据验证、风险状态流转、筛选结论写入与评测关闭等敏感操作会先请求你审批。

边界：研究助手**不执行系统命令、不直接写任意文件**；需要自由生成 HTML、脚本或其他临时产物时，请切到「智能助手」或「深度研究」，它们具备沙箱执行能力。研究报告类文件一律通过导出工具落盘，并附在对话里供下载。

| 入口 | 关键操作 | 产出 |
| --- | --- | --- |
| 科研罗盘 → 右侧 AI 研究助手 / 科研助手页 | 用自然语言下达任务（例如"把这三篇论文按方法/数据集/局限对比，并给出证据"，或"导出项目报告""同步引用图谱""跑一次论文分析"） | 带工具调用记录的回答，写操作会落库 |

### 8. 证明效果（可复现实验）

固定语料、模型与数据集，跑 RAG 评估、检索消融与单/多 Agent 盲评；再用一次性匿名邀请收集 SUS 用户评测。

| 入口 | 关键操作 | 产出 |
| --- | --- | --- |
| 知识库详情 → RAG 评估 / 评估基准 / 消融实验 | 建基准 → 开始评估 → 查看逐题明细 / 变体对比 | Recall@K、F1、综合评分与指纹化实验报告 |
| 科研罗盘 → 用户评测 | 新建评测 → 复制匿名链接发给同学 → 查看报告 | SUS、任务评分与匿名文字反馈 |

## 它不做什么（边界要说清）

- **不代写论文、不生成虚假引用**：综述与结论只能引用通过校验的真实片段，无法支撑的内容会显式标为"未支持结论"。
- **不替你做领域判断**：研究机会、趋势、机会分都是基于当前文献库的统计与排序，不等于领域共识。
- **没有真实人工评分时不下结论**：对比实验、用户评测在样本为 0 时只显示"暂无数据"，不会推断优劣。
- **严格图谱模式不静默降级**：图谱未同步时直接失败并提示，避免把普通检索包装成图谱增强结果。

## 30 分钟上手路径

1. 建库并上传 5～10 篇你熟悉的论文（学术分块）。
2. 在「智能检索」里问一个你已知答案的问题，验证证据是否对得上原文。
3. 用「证据综述」生成一份小综述，检查"未支持结论"是否合理。
4. 建一个研究项目，把上面的检索与综述归集进去，导出一份报告。

按步骤的完整操作见 [从选题到成稿：一条可追溯的科研流水线](./research-workflow.md)。
