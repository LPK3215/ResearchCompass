# 科研罗盘 ResearchCompass

ResearchCompass 面向需要管理、检索和分析学术论文的研究者。它将论文原文、学术语义分块、引用图谱、结构化分析和实验评测放在同一个可追溯工作流中。

## 开始使用

1. 管理员创建或选择 Milvus 知识库，并配置对话、向量和重排序模型。
2. 上传论文 PDF，解析时选择 Academic Paper 分块策略，等待解析与索引完成。
3. 在“科研罗盘”中选择同一知识库，确认论文元数据和章节分块。
4. 先使用本地混合模式验证检索和原文证据，再按需要同步引用图谱并使用严格图谱模式。

## 研究项目

“研究项目”是科研罗盘的默认工作区，用于把分散在论文库、检索、证据综述、论文分析和实验评估中的成果组织成一个持续推进的课题。项目属于创建者个人，并绑定一个当前用户可访问的知识库；即使知识库由多人共享，其他用户也不能读取或修改该项目。

创建项目时应填写明确的项目名称和研究问题，并可补充说明、标签、目标日期、当前进度和下一步行动。项目列表支持搜索、状态筛选和分页，项目详情集中展示进度、成果数量与最近活动。

### 归集研究成果

项目可以归集五类既有成果：

- 论文：保留题目、作者、年份等快照，可继续打开论文详情和原文证据。
- 检索运行：保留研究问题、模式与运行状态，可按原始配置恢复结果并继续检索。
- 证据综述：保留综述主题与状态，可回到对应综述查看证据和导出结果。
- 论文分析：保留分析对象、模式与状态，可继续查看结构化分析报告。
- 消融实验：保留实验名称、状态和知识库信息，可直接打开指定实验报告。

候选成果按当前项目知识库、当前用户权限和成果类型筛选，支持搜索、分页与批量归集。每项成果可以记录项目内备注；同一成果不会在同一项目中重复归集。

项目保存的是成果引用和必要快照，不会复制或接管原始成果。原始成果被删除后，项目仍显示当时归集的信息并明确标记为“源成果不可用”；删除项目只会删除项目、项目备注和活动记录，不会删除论文、检索、综述、分析或实验本身。

### 项目生命周期

项目状态分为“进行中”“已完成”和“已归档”。进行中的项目可以编辑资料、调整进度、归集成果和维护备注；完成后进度固定为 100%，成果关系只读，但仍可修订项目说明或进一步归档；归档后项目整体只读。需要继续推进时，可以先恢复为进行中。完成、归档、恢复、编辑和成果变更都会进入最近活动时间线。

## 检索模式

| 模式 | 数据路径 | 适用场景 |
| --- | --- | --- |
| 本地混合 | 查询改写、向量与 BM25 召回、RRF、重排序、论文证据聚合 | 本地论文库检索、无外部图谱环境、稳定演示 |
| 严格图谱 | 本地混合检索加论文引用图谱预检、PPR 扩展与关系解释 | 引用网络分析、图谱增强实验 |

严格图谱模式不会在图谱缺失或失败时静默降级。界面和运行记录会保留实际检索模式，避免把本地检索结果误写成图谱增强结果。

## 检索工作台

每次成功检索都会保存当时返回的论文排序、证据、图谱扩展、公开模型配置和阶段耗时。重新进入“智能检索”后，可以从历史中恢复完整结果，不需要依赖仍然打开的浏览器页面。

- 历史按当前用户和当前知识库隔离，切换知识库不会混入其他库的结果。
- 重要检索可以置顶；不再需要的已完成或失败记录可以删除，删除后不可恢复。
- 历史记录和当前结果都可以按原研究问题与筛选配置重新执行，以当前语料和模型生成新运行。
- 可以把研究问题、年份和候选数量直接带入“证据综述”，再创建独立、可验证的综述运行。
- 旧版本中没有结果快照的运行仍显示原始问题、配置和错误状态，并提供重新执行入口。

## 工作区

- 研究项目：管理课题生命周期、进度、下一步行动和跨工作流研究成果。
- 论文库：分页浏览论文、章节、标签和元数据，导出 BibTeX。
- 智能检索：管理个人检索历史，恢复、置顶、删除或重跑结果，查看召回证据、阶段耗时、重排分数和引用关系，并继续生成证据综述。
- 引用图谱：同步 Semantic Scholar 元数据，浏览引用网络和两跳关系。
- 论文分析：运行单 Agent 或四阶段多 Agent 分析并查看结构化报告。
- 证据综述：基于检索快照生成可验证综述，导出 Markdown 或 DOCX。
- 研究趋势与机会：根据当前论文库的年份、关键词和图谱覆盖生成确定性统计。
- 实验评估：固定语料、模型和数据集，运行检索消融及单/多 Agent 盲评。
- 用户评测：通过一次性匿名邀请收集 SUS 与任务体验数据。

## 可复现验收

正式演示或实验应固定以下信息：

- 论文集合及内容哈希；
- Academic 分块参数和嵌入模型；
- 检索模式、Top-K、重排序模型及图谱快照；
- 对话模型、分析策略、实验数据集和 Judge 配置；
- 原始逐题结果、失败记录和最终汇总。

在“实验评估 → 消融实验”中先下载“固定语料清单”。清单按内容哈希稳定排序，记录嵌入模型、论文数量、文件名、内容哈希、分块数量和文件大小；正式实验应将该清单与评估基准、图谱快照和实验报告一起归档。创建实验时可加载标准四组配置，对比纯向量、BM25、向量与 BM25 混合、混合检索与知识图谱增强四条路径。这里的知识图谱增强是知识库检索配置，不等同于科研搜索中的严格学术引用图谱 PPR 链路；两者的实验结果应分别报告。

Semantic Scholar 属于外部可选能力。正式演示应提前完成图谱同步并保留可复现快照，避免把现场网络或外部限流作为核心链路前提。

## 结果边界

研究机会、趋势和多 Agent 报告是基于当前论文库和模型配置生成的辅助证据，不等同于领域共识。没有真实实验或用户样本时，系统不会推断策略优劣，也不应在对外材料中声明提升比例。
