# Changelog

All notable changes to ResearchCompass are documented here. The authoritative, detailed release history is maintained in [`docs/develop-guides/changelog.md`](docs/develop-guides/changelog.md); this root file is the concise repository-level entry point.

## [Unreleased]

### Added

- `README.zh-CN.md`: Chinese companion to the English primary README, with matching section structure and language links.
- `FAQ.md`, `SECURITY.md`, `AUTHORS`, `.pre-commit-config.yaml` and `backend/README.md`.
- Repository-backed architecture, workflow, sequence and data-flow diagrams under `docs/archify/`.
- `docs/assets/banner.svg` generated by `scripts/visualization/generate_banner.mjs`; the READMEs now use a centered hero, badges, navigation and interactive diagram links.
- Static project overview dashboard under `docs/project_overview/` with a `docs/index.html` entry and `.nojekyll` for classic GitHub Pages; it covers architecture, method, stack, directory tree, evaluation charts, API, quality and the docs index.
- `Makefile` targets for `test`, `test-web`, `smoke`, `eval-baseline`, `eval-ablation`, `eval-synthesis` and `docs-build`.

### Changed

- `README.md` is now the English primary README; `README.en.md` is kept as a compatibility pointer. Both READMEs share a centered hero, badge row and a 14-section structure including Visualization and FAQ.
- Documentation consistency pass: the VitePress home now reads its release tag, provider count and docs statistics from `backend/scripts/doc_stats.py`; Compose host/direct API port references and the latest unit/smoke counts were synchronized across docs.
- Root `CONTRIBUTING.md` and `CHANGELOG.md` are English single-version entry points; the detailed guides remain under `docs/develop-guides/`.
- `LICENSE` now includes the ResearchCompass/LPK3215 copyright line while retaining the upstream Yuxi MIT notice.
- `.gitignore` ignores the local `.archify/` build workspace; `.gitattributes` defines line-ending and binary rules.
- `backend/pyproject.toml`, `web/package.json` and `docs/package.json` metadata updated (description, author, license and package identity where applicable).
- `Makefile` checks now cover backend tests, frontend unit tests, smoke acceptance, fixed-corpus evaluation and the documentation build.

### Fixed

- `backend/pyproject.toml` declared `readme = "README.md"` without a backend README; the new `backend/README.md` makes the declared package readme resolvable.

## [v0.11.15] - 2026-10-21

Latest release tag. The detailed release notes, including the v0.11.0 capability close-out and the pre-release audit fixes, are in [`docs/develop-guides/changelog.md`](docs/develop-guides/changelog.md).

Highlights of the v0.11.0 line:

- Evidence-traceable research workflow: academic chunking, hybrid retrieval, evidence-constrained synthesis, research projects and exports.
- Fixed corpus evaluation: retrieval baseline, controlled reranker ablation and synthesis evidence coverage.
- Pre-release hardening: rate-limit tracking bounds, explicit account failure, integration-test knowledge-base cleanup, upload-size alignment, 404 page fixes and deterministic default knowledge-base selection.
- Documentation and verification consolidation: browser acceptance records, capability-gap ledger and reproducible release checks.
